# ورقة

منصة عربية لإدارة الطلاب وإنشاء الاختبارات وطباعتها وتصحيح التظليل من الصور وPDF.

هذه نسخة التشغيل المستقلة على Cloudflare Workers. المستودع يحتوي الكود والقوالب واختبارات ببيانات تجريبية فقط. بيانات الطلاب الفعلية وصور الأوراق ليست ضمنه.

## حالة التجهيز

رفع الكود إلى GitHub لا يعني أن الموقع الخارجي يعمل أو أن بيانات النسخة السابقة انتقلت. يلزم إكمال إعداد Cloudflare أدناه. حتى ذلك الوقت يبقى الموقع الحالي متاحًا دون تغيير.

## إعداد Cloudflare لأول مرة

1. أنشئ قاعدة D1 باسم `waraqa-db` وحاوية R2 باسم `waraqa-files` في حسابك.
2. عدّل `database_id` في `wrangler.jsonc` إلى المعرّف الذي أعطاك Cloudflare. عدّل اسم الحاوية إذا اخترت اسمًا آخر.
3. طبّق مخطط قاعدة البيانات مرة واحدة: `npx wrangler d1 migrations apply waraqa-db --remote`.
4. اربط المستودع من Workers & Pages. اختر فرع `main`، وأمر البناء `npm run build`، وأمر النشر `npx wrangler deploy`. استخدم Node 22 أو أحدث.
5. فعّل Cloudflare Access على كل مسارات الموقع وعلى رابط workers.dev أيضًا، واختر تسجيل الدخول بالبريد ورمز التحقق لمستخدمك. يجب حماية الزيارات الفعلية، وليس المعاينات فقط.
6. أضف متغيرات التشغيل التالية في إعدادات Worker؛ لا تضع معلومات حسابك أو الرموز السرية في المستودع:

| المتغير | القيمة |
| --- | --- |
| `ACCESS_TEAM_DOMAIN` | نطاق فريقك مثل `team.cloudflareaccess.com` |
| `ACCESS_AUD` | معرّف جمهور تطبيق Access |
| `ALLOWED_EMAILS` | بريدك المسموح له بالدخول؛ يمكن فصل أكثر من بريد بفاصلة |

يتحقق الخادم من توقيع جلسة Access ومن المصدّر والجمهور والصلاحية والبريد المسموح. لا توجد صلاحية اعتمادًا على رؤوس يرسلها الزائر. قبل اكتمال الإعداد يرفض الخادم الوصول؛ لا توجد وضعية دخول عامة للبيانات.

## النطاق الخاص والتحديث التلقائي

بعد نجاح التشغيل الأول أضف النطاق الذي تملكه من إعدادات Worker والنطاقات. ربط GitHub عبر Workers Builds ينشر تحديثات `main` تلقائيًا. الربط يتطلب إعدادًا داخل حسابك في Cloudflare؛ لا يفعّل بمجرد رفع هذا المستودع.

التعديلات التي ننفذها في ChatGPT يجب رفعها إلى هذا المستودع أيضًا، ثم تنشرها Cloudflare. يحتفظ مشروع التحرير بأمر تصدير محدد الملفات لتحديث النسختين من الكود نفسه. لا تتم مزامنة أي ملفات أو محادثات أخرى من حساب ChatGPT.

## نقل بياناتك الحالية

في الموقع الحالي اضغط «نسخة احتياطية» وانتظر تنزيل JSON بما فيه صور الأوراق. بعد تشغيل الموقع المستقل وتسجيل الدخول، استخدم «استعادة البيانات» وارفع النسخة، ثم انتظر «محفوظ في حسابك». تحقّق من الطلاب والاختبارات والنتائج والصور قبل اعتماد النقل. لا ترفع النسخة الاحتياطية إلى GitHub. النسخة السابقة لا تُحذف.

## التطوير والتحقق

```sh
npm install
npm run build
npm test
```

القوالب Word في `public/templates`. بيانات الاختبارات في `tests/fixtures` مصطنعة. تصحيح التظليل تجريبي ويتطلب مراجعة المعلم، ولا يقيّم النصوص المقالية آليًا. يعتمد استيراد أسئلة PDF على قالب Word النصي؛ لا يشمل OCR للصور.

لم تُجرّب هذه النسخة بعد على حساب Cloudflare الإنتاجي للمالك. يلزم اختبار تسجيل الدخول وحفظ البيانات والصور على الاستضافة بعد إتمام الإعداد.
