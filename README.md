# ورقة على GitHub Pages

منصة عربية لإنشاء الاختبارات وإدارة الطلاب والطباعة وقراءة التظليل، تعمل من GitHub Pages دون Cloudflare أو اشتراك R2.

## تفعيل الموقع

1. افتح المستودع في GitHub، ثم Settings ثم Pages.
2. تحت Build and deployment اختر GitHub Actions مصدرًا للنشر.
3. افتح Actions ثم Publish Waraqa to GitHub Pages. يشتغل النشر عند تحديث main، ويمكن تشغيله يدويًا من Run workflow.

يعرض قسم Pages الرابط الفعلي بعد نجاح النشر. اختيار GitHub Actions خطوة مطلوبة في إعدادات المستودع؛ وجود ملفات الموقع وحده لا يعني أنه منشور.

الاستضافة المجانية عبر GitHub Free تتطلب بقاء المستودع عامًا. استخدام نطاق GitHub الافتراضي لا يحتاج شراء نطاق خاص.

## أين تحفظ البيانات

الطلاب والاختبارات والنتائج تحفظ في LocalStorage، وصور الأوراق في IndexedDB داخل متصفح المستخدم. لا تُرفع بيانات الطلاب إلى GitHub ولا توجد قاعدة بيانات مشتركة في هذه النسخة. ملفات المستودع تحتوي الكود والقوالب وبيانات اختبارات مصطنعة فقط.

لا توجد مزامنة تلقائية بين الأجهزة أو بين Safari والمتصفحات الأخرى. مسح بيانات الموقع أو استخدام التصفح الخاص قد يفقد البيانات؛ احتفظ بنسخ احتياطية تتضمن الصور.

لنقل بياناتك من النسخة السابقة: افتح الموقع السابق واضغط «نسخة احتياطية»، ثم افتح الموقع الجديد واختر «استعادة البيانات» وارفع ملف JSON. تحقق من الأسماء والاختبارات والصور بعد الاستعادة. لا ترفع النسخ الاحتياطية إلى المستودع.

## التحديثات التلقائية

الملف `.github/workflows/pages.yml` يبني وينشر الموقع عند رفع تحديث إلى main. يبدأ البناء من `public` و`site/index.html` ويجهز نسخة GitHub Pages من دون اتصال بخادم حفظ أو ChatGPT. لا يحتاج Workflow أي مفاتيح خدمات أو اشتراكات تخزين.

للتعديل من المحادثة نحدّث المشروع نفسه ونرفع التغييرات إلى هذا المستودع، ثم تنشرها GitHub Actions. لا تنتقل محادثات أخرى أو ملفات حسابك إلى المستودع. ظهور رابط جديد أو تحديثه يتطلب نجاح عملية النشر.

## الاختبارات والبناء

```sh
node tests/local-storage.cjs
npm run build
```

لا يحتاج بناء نسخة Pages تثبيت حزم npm. بقيت ملفات Cloudflare السابقة اختيارية وغير مستخدمة في هذا النشر. أمر البناء الافتراضي `npm run build` يستخدم GitHub Pages، وأوامر Cloudflare لها لاحقة صريحة.

قوالب Word متاحة في `public/templates`. قراءة التظليل تجريبية وتحتاج مراجعة المعلم، ولا تشمل تقييم المقال آليًا. استيراد أسئلة PDF يعتمد على القالب النصي، وليس OCR للصور الممسوحة.


### كاميرا الهاتف
من التصحيح اختر «تصوير تلقائي بالكاميرا». تظهر علامات خضراء وتُلتقط الورقة بعد ثبات المربعات الأربع ووضوح الصورة. تحكم العدسات والتصغير يظهر بحسب ما يتيحه الهاتف للمتصفح؛ لا يُعرض تصغير وهمي. بعد الالتقاط اختر الطالب وراجع الدرجة الأولية تحت الصورة قبل اعتمادها. معالجة الصور داخل المتصفح. يمكن استخدام «الكاميرا العادية» عند عدم إتاحة التصوير المباشر.
